# WinLanChat 1.0.3

## English

- Check for updates directly in settings using GitHub Releases.
- Read release notes, download with progress and cancel a download at any time.
- Verify installer size and SHA-256 before allowing installation.
- Install a downloaded update after confirmation; WinLanChat closes safely and reopens after setup.
- Pending file transfers, offers and unsent attachments block installation until handled.
- Optional update checks at startup, disabled by default. LAN chat continues to work without internet.
- Russian and English update UI.

Download `WinLanChat-1.0.3-win-x64-Setup.exe`. The Windows x64 installer includes
.NET Desktop Runtime. Install this version manually once to enable future in-app
updates. Settings and saved files are preserved; current chat history is not saved.

## Русский

- Проверка обновлений через GitHub Releases прямо в настройках.
- Описание изменений, загрузка с прогрессом и возможность отмены.
- Проверка размера установщика и SHA-256 перед установкой.
- Установка после подтверждения: WinLanChat завершает работу и открывается после обновления.
- Перед установкой нужно завершить передачи файлов, обработать предложения и убрать неотправленные вложения.
- Необязательная проверка при запуске, по умолчанию отключённая. Чат в локальной сети работает без интернета.
- Интерфейс обновлений на русском и английском.

Скачайте `WinLanChat-1.0.3-win-x64-Setup.exe`. Установщик для Windows x64 уже
содержит .NET Desktop Runtime. Эту версию нужно один раз установить вручную,
чтобы следующие обновления устанавливались из приложения. Настройки и сохранённые
файлы остаются; текущая история переписки не сохраняется.
